#33 · #34

OpenAI (GPT-4o) & Anthropic (Claude)

The two most common production LLMs. OpenAI is the default; Anthropic Claude excels at long-context, instruction-following, and coding tasks.

🤖 OpenAI
pip install llama-index-llms-openai

from llama_index.llms.openai import OpenAI
from llama_index.core import Settings

Settings.llm = OpenAI(
    model="gpt-4o",
    temperature=0.1,
    max_tokens=1024
)

# Direct LLM call
llm = OpenAI(model="gpt-4o-mini")
resp = await llm.acomplete("Explain RAG")
🧠 Anthropic
pip install llama-index-llms-anthropic

from llama_index.llms.anthropic import Anthropic
from llama_index.core import Settings

Settings.llm = Anthropic(
    model="claude-sonnet-4-6",
    temperature=0.1,
    max_tokens=2048
)

# Direct call
llm = Anthropic(model="claude-sonnet-4-6")
resp = await llm.acomplete("Explain RAG")
gpt-4o
Best OpenAI model for RAG. 128k context. Fast + smart.
gpt-4o-mini
10x cheaper than gpt-4o. Use for high-volume, simpler tasks.
claude-sonnet-4-6
Best Claude for production. Excellent at long docs + following instructions.
claude-haiku-4-5
Fastest, cheapest Claude. Good for simple Q&A at scale.
💡 Both follow the same LlamaIndex interface — swapping providers is just changing the import and model name. No other code changes needed.
#35

Azure OpenAI — Enterprise Standard

Azure OpenAI is the same GPT models, but hosted within your Azure tenant. Required for enterprises with data residency requirements, compliance controls (SOC2, HIPAA), or existing Azure contracts.

Setup
pip install llama-index-llms-azure-openai

from llama_index.llms.azure_openai import AzureOpenAI
from llama_index.embeddings.azure_openai import AzureOpenAIEmbedding

llm = AzureOpenAI(
    model="gpt-4o",
    deployment_name="my-gpt4o-deployment",  # your Azure deployment name
    api_key="YOUR_AZURE_KEY",
    azure_endpoint="https://YOUR_RESOURCE.openai.azure.com",
    api_version="2024-02-01"
)

embed_model = AzureOpenAIEmbedding(
    model="text-embedding-3-small",
    deployment_name="my-embed-deployment",
    api_key="YOUR_AZURE_KEY",
    azure_endpoint="https://YOUR_RESOURCE.openai.azure.com",
    api_version="2024-02-01"
)
🏢 Azure uses deployment names (what you named it in Azure Portal) rather than model names. Make sure to set both model and deployment_name.
#36 · #37

Groq (Ultra-fast) & Ollama (Local)

Groq uses custom LPU hardware — generates tokens up to 10× faster than OpenAI. Ollama runs open-source LLMs fully locally on your machine.

⚡ Groq
pip install llama-index-llms-groq

from llama_index.llms.groq import Groq

llm = Groq(
    model="llama-3.3-70b-versatile",
    api_key="YOUR_GROQ_KEY"
)

# Groq models available:
# llama-3.3-70b-versatile
# llama-3.1-8b-instant  (fastest)
# mixtral-8x7b-32768
# gemma2-9b-it
🦙 Ollama
pip install llama-index-llms-ollama

# Pull model first:
# ollama pull llama3.2

from llama_index.llms.ollama import Ollama

llm = Ollama(
    model="llama3.2",
    base_url="http://localhost:11434",
    request_timeout=120.0
)

# Popular local models:
# llama3.2, mistral, codellama
# phi3, gemma2, qwen2.5
⚡ Use Groq when you need OpenAI-quality responses but 5–10× lower latency — great for real-time chat applications and agent loops where speed matters.
🔒 Use Ollama for air-gapped environments, dev without API costs, or when data privacy prevents using cloud LLMs.

Which LLM To Use — Decision Guide

Provider Speed Best For Avoid When
OpenAI GPT-4o Medium Default choice, best ecosystem support Cost-sensitive high-volume tasks
GPT-4o-mini Fast High-volume, simple Q&A, agents Complex reasoning or long docs
Claude Sonnet Medium Long docs, instruction-following, coding When OpenAI ecosystem tools needed
Azure OpenAI Medium Enterprise compliance, data residency Startups with no Azure infrastructure
Groq Ultra-fast Real-time chat, low-latency agent loops Largest models (limited selection)
Ollama GPU-dependent Local dev, air-gapped, no API cost Production without dedicated GPU hardware
Mistral Fast EU data residency, code generation Complex multi-step reasoning
AWS Bedrock Medium AWS-native stacks, multi-model access Non-AWS infrastructure teams
Gemini 1.5 Pro Slower Massive context (1M tokens), multimodal Simple fast Q&A tasks
🔑 All LLMs follow the exact same LlamaIndex interface. Once your app works with one provider, switching to another is a single line change in your Settings config.
