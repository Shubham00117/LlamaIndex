#27

OpenAI Embeddings

The most widely used embedding model in production. Fast, reliable, and integrates natively with OpenAI's LLMs. Two generations — always use text-embedding-3 for new projects.

Setup
from llama_index.embeddings.openai import OpenAIEmbedding
from llama_index.core import Settings

# Small — cheap, fast, great for most use cases
Settings.embed_model = OpenAIEmbedding(
    model="text-embedding-3-small"   # 1536 dims
)

# Large — better quality for complex retrieval
Settings.embed_model = OpenAIEmbedding(
    model="text-embedding-3-large",   # 3072 dims
    dimensions=1024   # optional: reduce dims to save cost
)
text-embedding-3-small

text-embedding-3-large

text-embedding-ada-002
Legacy · 1536 dims · Avoid for new projects
✅ Start with text-embedding-3-small. Only upgrade to large if evaluation shows retrieval quality issues.
#28

HuggingFace Local Embeddings

Run embedding models locally — zero API cost after download. Ideal for high-volume ingestion pipelines where embedding cost adds up, or when data cannot leave your servers.

Setup
pip install llama-index-embeddings-huggingface

from llama_index.embeddings.huggingface import HuggingFaceEmbedding
from llama_index.core import Settings

# Best general-purpose local model
Settings.embed_model = HuggingFaceEmbedding(
    model_name="BAAI/bge-small-en-v1.5"  # 384 dims, ~130MB
)

# Higher quality option
Settings.embed_model = HuggingFaceEmbedding(
    model_name="BAAI/bge-large-en-v1.5"  # 1024 dims, ~1.3GB
)

#29

Ollama Embeddings — Fully Local

Ollama lets you run open-source LLMs and embedding models locally via a simple server. No Python dependencies for the model itself — just run the Ollama server and call it like an API. Perfect for fully air-gapped environments.

Setup
# 1. Install Ollama (Mac/Linux): https://ollama.ai
# 2. Pull an embedding model
ollama pull nomic-embed-text

# 3. Use in LlamaIndex
pip install llama-index-embeddings-ollama

from llama_index.embeddings.ollama import OllamaEmbedding
from llama_index.core import Settings

Settings.embed_model = OllamaEmbedding(
    model_name="nomic-embed-text",
    base_url="http://localhost:11434"  # default Ollama port
)
nomic-embed-text
768 dims · Best quality/speed local model via Ollama
mxbai-embed-large
1024 dims · High quality, state-of-art on MTEB benchmark
🔒 Ollama embeddings never leave your machine — ideal for confidential data, regulated industries (HIPAA, GDPR) where cloud APIs are restricted.
#30

Cohere Embeddings

Cohere's embed-v3 models are multilingual and specifically trained for retrieval tasks. Strong choice when your documents are in multiple languages or when OpenAI isn't an option.

Setup
pip install llama-index-embeddings-cohere

from llama_index.embeddings.cohere import CohereEmbedding
from llama_index.core import Settings

Settings.embed_model = CohereEmbedding(
    cohere_api_key="YOUR_KEY",
    model_name="embed-english-v3.0",
    input_type="search_document"    # use "search_query" at query time
)
🌍 Cohere's embed-multilingual-v3.0 supports 100+ languages in a single model — best choice for international or multilingual RAG applications.
#31

Custom Embedding Models

If you have a fine-tuned or proprietary embedding model, subclass BaseEmbedding to plug it into LlamaIndex's ecosystem seamlessly.

Pattern
from llama_index.core.embeddings import BaseEmbedding
from typing import List

class MyCustomEmbedding(BaseEmbedding):
    def _get_text_embedding(self, text: str) -> List[float]:
        # Call your model/API here
        return my_model.encode(text).tolist()

    def _get_query_embedding(self, query: str) -> List[float]:
        # Often same as text, but can differ
        return my_model.encode(query).tolist()

    async def _aget_query_embedding(self, query: str) -> List[float]:
        return self._get_query_embedding(query)

# Use like any other embed model
Settings.embed_model = MyCustomEmbedding()

Embedding Dimensions & Similarity Metrics

Understanding dimensions and similarity metrics helps you make informed trade-offs between cost, speed, and quality — and ensures your vector store is configured correctly.

Dimensions by model

1024

Similarity metrics
Metric When to Use Note
cosine Default for almost all RAG use cases Direction-based, not affected by vector magnitude
dot_product When vectors are normalized (same as cosine then) Faster computation, equivalent to cosine if normalized
euclidean (L2) Image embeddings, some fine-tuned models Magnitude matters — less common in text RAG
Critical rule — don't mix models
# ❌ WRONG — embedding and querying with different models
#    Produces garbage results, no errors thrown!
# Index built with: text-embedding-3-small
# Query using:      text-embedding-3-large  ← WRONG

# ✅ CORRECT — always use the same model for both
Settings.embed_model = OpenAIEmbedding(model="text-embedding-3-small")
# All indexing AND all queries automatically use this model
⚠️ The embed_model in Settings applies to both indexing and querying. Never switch models on an existing index without rebuilding it from scratch.
Dimensions trade-off summary
Higher dims
Better semantic quality · More storage · Slower similarity search · Higher API cost
Lower dims
Faster search · Less storage · Lower cost · Slight quality loss
Matryoshka models
text-embedding-3 supports reducing dims via dimensions= param without retraining
