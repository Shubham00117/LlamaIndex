# Topic 6: Embeddings

## Overview
Embedding models convert text into numerical vectors for similarity search. LlamaIndex supports multiple providers — choose based on quality, cost, and privacy needs.

## Providers
| Provider | Package | Use Case |
|----------|---------|----------|
| OpenAI | `llama-index-embeddings-openai` | Best quality, cloud |
| HuggingFace | `llama-index-embeddings-huggingface` | Free, local, cost saving |
| Ollama | `llama-index-embeddings-ollama` | Fully local/offline |
| Cohere | `llama-index-embeddings-cohere` | Alternative cloud option |
