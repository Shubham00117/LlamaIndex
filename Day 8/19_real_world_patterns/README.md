# Topic 19: Real-World Project Patterns
## Overview
Complete project patterns that combine multiple LlamaIndex features into production-ready solutions.

## Patterns
- Enterprise Document Q&A (RAG)
- Multi-document research agent
- Chatbot with persistent memory
- Multi-tenant RAG (user-level data isolation)
- Corrective RAG (self-correcting retrieval)
- Full-stack web app (LlamaIndex + FastAPI + React)
