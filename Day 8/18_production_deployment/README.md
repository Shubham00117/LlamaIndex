# Topic 18: Production Deployment
## Overview
Deploy LlamaIndex applications to production with FastAPI, async query engines, caching, Docker, and microservice architecture.

## Key Areas
- FastAPI + LlamaIndex REST API
- Async query engine for scalable endpoints
- LLM response caching & embedding caching
- Rate limiting & cost optimization
- Dockerizing a LlamaIndex app
- llama_deploy for microservice deployment
- CI/CD with GitHub Actions
