# Topic 8: Query Engine & Retrieval

## Overview
The Query Engine is how you ask questions against your indexed data. LlamaIndex offers multiple response modes and retrieval strategies.

## Key Concepts
- **Basic Query Engine** (#41): Response modes — compact, refine, tree_summarize
- **Streaming** (#42): Stream tokens as they're generated
- **Metadata Filtering** (#43): Filter retrieval by metadata
- **BM25 Retriever** (#45): Keyword/sparse retrieval
- **Hybrid Search** (#46): Combine BM25 + vector search
- **Advanced Retrievers** (#47-52): Auto-merging, recursive, fusion, router
