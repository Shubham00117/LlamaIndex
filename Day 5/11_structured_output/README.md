# Topic 11: Structured Output & Data Extraction
## Overview
Extract structured data from LLM responses using Pydantic models, query databases with natural language, and parse tables from documents.

## Key Features
- **Pydantic structured output** — Force LLM to return specific schemas
- **LlamaExtract** — Schema-based extraction from documents  
- **Text-to-SQL** — Natural language to SQL queries
- **CSV querying** — Query CSV files with natural language
