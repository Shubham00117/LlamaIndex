Faithfulness & Answer Relevancy Evaluators

The two most important RAG metrics. Faithfulness checks if the answer is grounded in the retrieved context (no hallucinations). Relevancy checks if the answer actually addresses the question.

🎯
Faithfulness
0.0–1.0
Is every claim in the answer supported by the retrieved context?
💬
Relevancy
0.0–1.0
Does the answer address what was actually asked?
📄
Context Recall
0.0–1.0
Did retrieval find all the relevant context needed?
✅
Correctness
1–5
Is the answer factually correct? Requires ground truth.
Faithfulness evaluator (#91)
from llama_index.core.evaluation import FaithfulnessEvaluator

# Uses an LLM judge to check grounding

print(result.feedback)   # LLM explanation of why it passed/failed

⚠️ Faithfulness below 0.8 means your RAG is hallucinating — the LLM is adding information not in the retrieved context. Fix by improving retrieval (get better chunks) or tightening the system prompt.
#93

Context Recall & Answer Correctness

Context Recall measures whether retrieval found all the relevant information. Correctness compares the answer to a ground-truth answer — both require a labeled evaluation dataset.

Context evaluator — did retrieval find what it needed?
from llama_index.core.evaluation import ContextRelevancyEvaluator

context_eval = ContextRelevancyEvaluator(llm=OpenAI(model="gpt-4o"))

# Checks: are the retrieved nodes relevant to the query?
result = await context_eval.aevaluate_response(
    query="What were the key risks in Q3?",
    response=response
)

# Per-node scores — see which chunks were actually useful
for node_result in result.source_nodes:
    print(f"Node: {node_result.node.text[:80]}...")
    print(f"Relevant: {node_result.score}")
Answer correctness — requires ground truth
from llama_index.core.evaluation import CorrectnessEvaluator

correctness_eval = CorrectnessEvaluator(llm=OpenAI(model="gpt-4o"))

# Need a reference answer to compare against
result = await correctness_eval.aevaluate(
    query="What was Q3 revenue?",
    response="Q3 revenue was $4.2M",
    reference="Q3 2024 revenue was $4.2 million, a 18% increase from Q2."
)

print(result.score)     # 1–5 scale
print(result.feedback)  # "Answer is correct but missing the growth %"
💡 Context Recall diagnoses retrieval problems. Low context recall = wrong chunks retrieved. Fix by trying larger top_k, hybrid search, or better metadata filtering.

You need test questions to run evaluations — but creating them manually is slow. LlamaIndex can generate synthetic (question, context, answer) triples from your documents automatically. RAGAS is a framework that bundles multiple metrics into one evaluation pipeline.

RAGAS — multi-metric RAG evaluation (#95)

RAGAS (Retrieval Augmented Generation Assessment) is the most popular framework for holistic RAG evaluation. It combines faithfulness, answer relevance, context precision and recall in one automated pipeline.

Faithfulness Generation
Claims in answer ÷ Total claims
verified in retrieved context
Measures hallucination rate. 1.0 = every claim is supported.
Answer Relevance Generation
avg cosine_sim(generated_questions,
original_question)
Reverse-generates questions from answer — checks if answer fits the question.
Context Precision Retrieval
Relevant nodes in top-k ÷ Total
nodes retrieved
Measures retrieval signal-to-noise. Low = too much irrelevant context sent to LLM.
Context Recall Retrieval
Ground truth claims found in
context ÷ Total ground truth claims
Did retrieval find everything needed? Low = relevant info missed.

from ragas import evaluate
from ragas.metrics import faithfulness, answer_relevancy, context_precision, context_recall
from datasets import Dataset

# Build evaluation dataset
eval_data = {
    "question":  ["What is Q3 revenue?", ...],
    "answer":    [response.response, ...],
    "contexts":  [[n.text for n in response.source_nodes], ...],
    "ground_truth": ["Q3 revenue was $4.2M", ...]
}

dataset = Dataset.from_dict(eval_data)

# Run all RAGAS metrics at once
scores = evaluate(
    dataset,
    metrics=[faithfulness, answer_relevancy, context_precision, context_recall]
)
print(scores)
# {'faithfulness': 0.91, 'answer_relevancy': 0.87,
#  'context_precision': 0.78, 'context_recall': 0.85}
📊 Target scores: Faithfulness > 0.85, Answer Relevancy > 0.80, Context Precision > 0.75, Context Recall > 0.80. These are reasonable baselines — tune based on your domain's requirements.

Eval pipeline for CI/CD (#98)

Run evals automatically on every code change to catch regressions before they reach production.

# ci_eval.py — run in CI pipeline (GitHub Actions, etc.)
import asyncio, json, sys

async def run_regression_eval():
    # Load golden eval dataset (checked into repo)
    questions = json.load(open("tests/eval_dataset.json"))

    runner = BatchEvalRunner(
        evaluators={"faithfulness": FaithfulnessEvaluator(),
                    "relevancy":    RelevancyEvaluator()},
        workers=8
    )
    results = await runner.aevaluate_queries(
        query_engine=query_engine,
        queries=questions["questions"]
    )

    # Assert minimum quality thresholds
    avg_faith = sum(r.score for r in results["faithfulness"]) / len(results["faithfulness"])

    if avg_faith < 0.80:
        print(f"❌ REGRESSION: faithfulness={avg_faith:.3f} (threshold: 0.80)")
        sys.exit(1)

    print(f"✅ PASS: faithfulness={avg_faith:.3f}")

asyncio.run(run_regression_eval())
