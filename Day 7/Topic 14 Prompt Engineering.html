#84

Custom System Prompts for Query & Chat Engines

The default system prompt is generic. A well-crafted system prompt gives the LLM a persona, scope, tone, and rules — dramatically improving answer quality and consistency for domain-specific applications.

Anatomy of a good RAG system prompt
Role & Persona
You are an expert financial analyst assistant for Acme Corp. You answer questions strictly based on the provided company documents.
Rules & Constraints
- Only use information from the provided context. Never use external knowledge.
- If the answer is not in the context, say "I don't have that information in the provided documents."
- Always cite the source document and page number when possible.
- Use professional, concise language. Avoid speculation.
Context Placeholder
{context_str} ← LlamaIndex injects retrieved chunks here
Query Placeholder
{query_str} ← User's question injected here
Setting system prompt on QueryEngine
from llama_index.core import PromptTemplate

system_prompt = """You are an expert financial analyst for Acme Corp.
Answer only from the provided context. If not found, say so clearly.
Always cite your source document.

Context:
{context_str}

Question: {query_str}
Answer:"""

qa_prompt = PromptTemplate(system_prompt)

query_engine = index.as_query_engine()

# Override the default QA prompt
query_engine.update_prompts({
    "response_synthesizer:text_qa_template": qa_prompt
})
Setting system prompt on ChatEngine
chat_engine = index.as_chat_engine(
    chat_mode="condense_plus_context",
    system_prompt="""You are a helpful assistant for Acme Corp HR department.
You only answer questions about HR policies, benefits, and employee procedures.
If asked about anything outside HR, politely redirect the user.
Always be professional, empathetic, and concise."""
)
Before vs After — system prompt impact
❌ Without custom prompt
Q: What is our vacation policy?

A: Vacation policies typically include PTO accrual rates based on tenure. Common policies provide 10–15 days for new employees, increasing with years of service. Some companies offer unlimited PTO...
← Hallucinated generic info, not from documents
✅ With custom prompt
Q: What is our vacation policy?

A: According to the Employee Handbook (p.12), full-time employees receive 15 days PTO annually, accruing at 1.25 days/month. PTO resets on January 1st and unused days...
← Cites source, uses actual doc content
💡 Always explicitly instruct the LLM to say "I don't know" when context doesn't contain the answer. Without this, it will confidently hallucinate every time.

Prompt Templates — Customizing Per Use Case

LlamaIndex uses PromptTemplate with named variables. Every built-in prompt can be retrieved and overridden for full control over how the LLM is instructed at each stage of the pipeline.

Built-in prompt types you can override
text_qa_template
QA
Used when synthesizing an answer from retrieved context. Most important to customize.
refine_template
Refine
Used in "refine" response mode. Iterates over each chunk to refine the answer.
summary_template
Summary
Used in tree_summarize mode for building summary hierarchies.
condense_question_prompt
Chat
Used to condense chat history + new question into a standalone query.
chat_history_prompt
Chat
Controls how conversation history is formatted before being sent to the LLM.
keyword_extract_template
Retrieval
Used by keyword-based retrievers to extract terms from a query.
View & override any prompt
# See all prompts in use
prompts = query_engine.get_prompts()
for key, prompt in prompts.items():
    print(f"{key}:\n{prompt.get_template()}\n")

# Override text_qa_template with custom template
custom_qa = PromptTemplate(
    """You are a legal document analyst. Answer based ONLY on the context.
Always cite clause numbers. Use formal legal language.

Context: {context_str}
Legal Question: {query_str}
Legal Analysis:"""
)

query_engine.update_prompts({
    "response_synthesizer:text_qa_template": custom_qa
})
PromptTemplate with custom variables
# Define a template with custom variables beyond context/query
report_template = PromptTemplate(
    """You are analyzing documents for {company_name} in {industry}.
Today's date: {current_date}. Fiscal year: {fiscal_year}.

Context: {context_str}
Question: {query_str}

Provide a structured analysis with: Executive Summary, Key Findings, Risks."""
)

# Partially fill template variables
filled_template = report_template.partial_format(
    company_name="Acme Corp",
    industry="SaaS",
    current_date="2024-Q3",
    fiscal_year="FY2024"
)
# {context_str} and {query_str} still injected by LlamaIndex

query_engine.update_prompts({
    "response_synthesizer:text_qa_template": filled_template
})
🎛️ partial_format() is powerful — pre-fill static variables (company name, date, persona) at setup time, leaving only {context_str} and {query_str} for LlamaIndex to fill at runtime.

Prompt Usage Patterns with LlamaIndex Abstractions

LlamaIndex has prompt-specific patterns that work differently from raw LLM calls. Understanding these prevents common mistakes and helps you extract maximum quality from the pipeline.

Pattern 1 — Chain-of-thought in RAG prompts
cot_template = PromptTemplate(
    """Answer the question using the provided context.

Think step by step:
1. Identify the key facts in the context relevant to the question
2. Reason through the answer using only those facts
3. State your final answer clearly

Context: {context_str}
Question: {query_str}

Step-by-step reasoning:"""
)

# CoT forces the LLM to reason before answering
# Significantly reduces hallucination on complex questions
Pattern 2 — Few-shot examples in templates
few_shot_template = PromptTemplate(
    """Extract structured data from the document context.

EXAMPLE:
Context: "Revenue for Q1 was $2.4M, up 12% from Q1 last year."
Output: {{"period": "Q1", "revenue": 2400000, "growth_pct": 12}}

Context: {context_str}
Question: {query_str}
Output (JSON):"""
)

# Few-shot examples dramatically improve extraction accuracy
Pattern 3 — Prompt debugging
# See the final rendered prompt sent to LLM
from llama_index.core.callbacks import CallbackManager, LlamaDebugHandler

debug_handler = LlamaDebugHandler(print_trace_on_end=True)
callback_manager = CallbackManager([debug_handler])

Settings.callback_manager = callback_manager

# Run a query — will print full prompt + LLM response to console
response = query_engine.query("What is our cash position?")

# Inspect specific events
event_pairs = debug_handler.get_llm_inputs_outputs()
for pair in event_pairs:
    print("INPUT:", pair[0].payload["messages"])
    print("OUTPUT:", pair[1].payload["response"])
Prompt best practices — quick reference
Be explicit about scope
"Answer ONLY from the provided context" — not implied, must be stated
Define fallback behavior
"If the answer is not in the context, say 'I don't have that information'"
Specify format
"Respond in 2–3 sentences" or "Use bullet points" or "Respond as JSON"
Add persona
"You are a senior [domain] expert" — improves domain-appropriate language
Chain-of-thought
"Think step by step before answering" — reduces errors on complex questions
Few-shot examples
1–3 input/output examples boost extraction and classification accuracy
Use partial_format()
Pre-fill static context (company, date, persona) — keep templates DRY
Debug with LlamaDebug
Always inspect the actual rendered prompt — never assume what's sent
⚠️ The most common RAG prompt mistake: not telling the LLM what to do when it doesn't know. Without explicit fallback instructions, the LLM will always produce an answer — even if it has to make one up.
Pattern 4 — Per response mode prompt tuning
# Refine mode needs TWO templates: initial answer + refinement
initial_qa = PromptTemplate(
    """Answer from context. Be concise.
Context: {context_str}
Question: {query_str}
Answer:"""
)

refine_tmpl = PromptTemplate(
    """You have an existing answer: {existing_answer}
New context to consider: {context_msg}
Refine the answer if new info is relevant, otherwise keep existing.
Refined answer:"""
)

query_engine.update_prompts({
    "response_synthesizer:text_qa_template": initial_qa,
    "response_synthesizer:refine_template":  refine_tmpl
})
🔍 Always call query_engine.get_prompts() first to see the exact variable names used by LlamaIndex — use them exactly as shown so your custom template slots in correctly.
