# Topic 16: Evaluation
## Overview
Evaluate your RAG pipeline's quality with automated metrics: faithfulness, relevancy, context recall, and retrieval quality.

## Metrics
- **Faithfulness** — Is the answer grounded in the retrieved context?
- **Relevancy** — Is the answer relevant to the question?
- **Context Recall** — Did retrieval find the right information?
- **Retrieval Evaluation** — Precision and recall of the retriever
