# Topic 12: Agents
## Overview
Agents are autonomous LLM-powered decision makers that can use tools, reason step-by-step, and call other agents.

## Patterns
- **ReAct Agent** — Think → Act → Observe loop
- **FunctionCalling Agent** — Uses function/tool calling
- **Custom Tools** — Define your own agent tools
- **Agent Memory** — Short-term + long-term memory
- **Multi-Agent** — Agents calling other agents
